# 🤖 AI-Powered Personal Portfolio Chatbot

An AI-powered personal portfolio chatbot that allows recruiters and visitors to interact with my portfolio using natural language.

The chatbot provides information about my technical skills, projects, interests, and career goals through an interactive conversational interface.

## 📌 Features

- 🤖 AI-powered conversational chatbot
- 💬 Natural-language interaction
- 🧠 Conversation history for follow-up questions
- ⚡ Gemini API integration
- 💻 Responsive and modern UI
- ⌨️ Enter-to-send functionality
- 💡 Quick-question buttons
- ⏳ Animated AI typing indicator
- 🛡️ Error handling and API retry mechanism
- 🔗 Frontend and backend communication using REST API
